# IEX Order Book (Plan A of 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A C++20 order book with price-time priority, fed by a streaming
decoder for real IEX DEEP+ order-by-order data, proven correct against
IEX's own DEEP and TOPS feeds and measured for throughput and latency.

**Architecture:** Two new static libraries beside `pkmn_engine_core`:
`pkmn_book` (pure order book, no I/O, integer prices) and `pkmn_md`
(pcapng reader over zlib, IEX-TP framing, sequence tracking, DEEP+/DEEP/TOPS
decoders emitting one shared event type). Command-line tools in
`cpp/tools/` drive them over real HIST files. Nothing here touches the
backtester; Plans B-D (Pokemon book, UDP transport, research re-run) build
on these libraries.

**Tech Stack:** C++20, CMake >= 3.26, zlib, Catch2 v3.7.1 (existing
FetchContent), Python 3.12 + httpx for the downloader script, OrbStack
Ubuntu 24.04 arm64 VM for headline measurements.

**Spec:** `docs/superpowers/specs/2026-10-22-market-data-and-clob-design.md`
(the "Architecture", "IEX side" and "Measurement" sections are the ones
this plan implements).

**Plan series:** A = this plan (book core + IEX). B = Pokemon protocol,
daily ladder, book execution as engine default. C = UDP multicast
transport and gap recovery. D = research re-run, book vs formula. Each gets
its own plan written when the previous one lands.

## Global Constraints

- Branch `feat/iex-book` from `main`, **after** `feat/instrument-repair-horizon`
  is finished and merged (spec "Prerequisite"). Commit the spec as the
  branch's first commit.
- C++20; no `-ffast-math`, no `-ffp-contract=fast`, no `/fp:fast` anywhere.
  The book uses integer prices only (int64 ticks; IEX = 1/10000 dollar).
- `pkmn_book` and `pkmn_md` must not be linked into the `_engine` Python
  module in this plan, and `pkmn_md`/tools build only when `NOT SKBUILD`,
  so the wheel build gains no zlib dependency.
- Decoders must skip unknown message types and accept messages longer than
  the spec length (spec v1.06: "IEX reserves the right to add message types
  and grow the length of any messages").
- Decoding must not allocate per message (spec "Architecture"): decoders
  write into caller-owned `BookEvent`/stats structs; only the book's own
  order storage may allocate.
- Never write a decompressed copy of a HIST file to disk. The downloader
  refuses any download that would leave < 2 GB free.
- HIST data goes under `data/iex/` (gitignored via `/data/`). No IEX bytes
  are committed: test fixtures are generated in code.
- Every published latency figure states hardware ("Apple M1 Pro, 7-vCPU
  OrbStack Ubuntu 24.04 arm64 VM"), timer, timer overhead, and gives
  p50/p99/p999/max, never an average alone.
- All four existing gates pass before every commit, plus the C++ suite on
  both macOS (`cpp/build`) and the VM (`cpp/build-linux`).
- Stop after each task, explain what and why at intern level, and wait for
  the owner's green light (project workflow rule).

## Review Focus

1. **A modify/delete/execute for an order id the book never saw** (orders
   resting before capture start, or lost in a gap): must be counted and
   ignored, never crash or corrupt another order. Test in Task 4.
2. **Duplicate packets at pcapng merge seams** (HIST files are merged from
   several captures): each message applied once. Test in Task 4.
3. **A truncated download** (partial `.gz`, or a pcapng block cut short):
   clean error naming the byte offset, no UB. Test in Task 2.
4. **An execution larger than the order's remaining size, or at a price
   different from the booking price** (spec: price improvement / sliding):
   execution reduces by `min(qty, remaining)`, counts an anomaly when
   clamped, and ignores the execution price for book state. Test in Task 1.
5. **Clear Book (`C`) mid-day:** that symbol's book is emptied and its order
   ids forgotten, so a later Add reusing an id is accepted. Test in Task 4.

**Interfaces:**
- Produces (namespace `pkmn::book`):
  ```cpp
  using Price = std::int64_t;  using Qty = std::int64_t;  using OrderId = std::uint64_t;
  enum class Side : std::uint8_t { Buy, Sell };
  struct Level { Price price; Qty qty; std::uint32_t orders; };
  struct Execution { OrderId resting_id; Price price; Qty qty; };
  struct Anomalies { std::uint64_t unknown_id = 0, duplicate_add = 0, exec_clamped = 0; };

  class OrderBook {
   public:
    bool add(OrderId id, Side side, Price price, Qty qty);          // false + duplicate_add if id live
    bool remove(OrderId id);                                         // false + unknown_id if absent
    bool modify(OrderId id, Price price, Qty new_total, bool keep_priority);
    Qty  execute(OrderId id, Qty qty);                               // passive fill by id; returns qty applied
    Qty  match(Side aggressor, Qty qty, Price limit, std::vector<Execution>& out); // aggressive; returns filled
    std::optional<Level> best(Side side) const;
    void depth(Side side, std::size_t n, std::vector<Level>& out) const;  // best first
    Qty  qty_at(Side side, Price price) const;
    std::size_t order_count() const;
    void clear();
    const Anomalies& anomalies() const;
  };
  ```
- `modify` semantics (DEEP+ v1.06 `M`): with `keep_priority` set and the price unchanged, the size changes in place; otherwise the order moves to the back of the queue at `price`. `new_total <= 0` removes the order.
- `execute` reduces by `min(qty, remaining)`, removes the order at zero, and keeps the residual's time priority (spec `L`). Clamping increments `exec_clamped`. The book never reads an execution price.
- `match` takes liquidity from the opposite side: best price first, FIFO within a level, never crossing `limit` (`Buy` takes asks <= limit, `Sell` takes bids >= limit). It never rests the remainder. The Pokemon book (Plan B) uses this.
- Baseline structure (Task 6 replaces it only if a measurement says so): `std::map` price levels per side, each holding a `std::list` of orders, plus `std::unordered_map<OrderId, iterator>`.

**Interfaces:**
- Produces (namespace `pkmn::md`):
  ```cpp
  struct Packet { std::int64_t ts_ns; std::span<const std::uint8_t> udp_payload; };
  class PcapngReader {
   public:
    explicit PcapngReader(const std::string& path);   // .pcapng/.pcap.gz (gzip) or raw; throws std::runtime_error
    bool next(Packet& out);                           // false at clean EOF; span valid until next call
    std::uint64_t bytes_consumed() const;             // decompressed offset, for error messages
  };
  ```
- Handles Section Header (`0x0A0D0D0A`, little-endian only), Interface Description (link type 1, reads `if_tsresol` option 9, default 6), and Enhanced Packet (type 6). Other block types are skipped by length. It strips Ethernet (14 bytes, plus 4 per 802.1Q tag), IPv4 (IHL) and UDP (8) to expose the UDP payload. Non-IPv4/UDP frames are skipped and counted.
- Reads through zlib (`inflateInit2` with `16 + MAX_WBITS`) into a ring buffer of at least 4 MiB, growing for a block larger than the buffer. Packets are spans into that buffer, not copies.
- Errors: a truncated block or a gzip stream ending mid-block throws `std::runtime_error` whose message contains `"truncated"` and the decompressed byte offset.

- `sequence.hpp` (Plan C reuses this for UDP):
  ```cpp
  enum class SeqVerdict : std::uint8_t { Next, Duplicate, Gap };
  class SequenceTracker {
   public:
    SeqVerdict observe(std::int64_t first_seq, std::uint16_t count); // heartbeat (count 0) is Next if first_seq == expected
    std::int64_t expected() const;
    std::uint64_t gaps() const, gap_messages() const, duplicates() const;
  };
  ```
  `Duplicate` = the whole range is below `expected` (skip the packet). If the range straddles `expected`, the decoder applies only the messages with seq >= expected (also `Duplicate` for the overlap count). `Gap` = `first_seq > expected`: record it, jump `expected`, and apply the packet.

  ```cpp
    book::OrderId order_id; book::Price price; std::int64_t qty; std::int64_t ts_ns;
  };
  ```
