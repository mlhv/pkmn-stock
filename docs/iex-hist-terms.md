# IEX Historical Data (HIST) terms of use

Read on 2026-10-22 at https://iextrading.com/iex-historical-data-terms/
(redirects to https://www.iex.io/legal/hist-data-terms; the link on
https://iextrading.com/trading/market-data/ is the old path and the
iexexchange.io variant 404s).

## Summary

Ten short clauses. Nothing forbids research use or local storage. The
terms are mostly attribution, IEX ownership, and disclaimers. This
project downloads the files for private research and does not
redistribute them (`data/iex/` is gitignored).

## Redistribution and attribution (clause 01, verbatim)

"If you distribute, sell, lease, furnish, or otherwise permit or provide
access to Investors' Exchange LLC ("IEX") historical data, you must cite
IEX as the source with the following text and link: "Data provided for
free by IEX. By accessing or using IEX Historical Data, you agree to the
IEX Historical Data Terms of Use.""

Any published result or artifact that exposes the data (not merely
derived statistics) must carry that citation and link.

## Other clauses worth remembering

- 02: no illegal use or violation of IEX or SEC rules.
- 03: IEX retains all proprietary rights in the data.
- 04-06, 09: data is "as is"; no liability for errors or omissions.
- 07: the user indemnifies IEX for noncompliance with the terms.
- 08, 10: the data reflects IEX activity only and is "a reference point
  only, rather than ... a basis for making trading decisions." This
  project uses it to model order-book mechanics for research, not to
  trade.
